# Nepheline Engine

Nepheline is a production-grade 3D game engine written in C17 on Vulkan 1.3.
It is data-oriented, GPU-driven, and designed bandwidth-first for a single
target: **240 FPS at native 3840×2160 on mid-range hardware** (RTX 3060 Ti).

The full plan, engineering principles, subsystem designs, and roadmap live in
[`CLAUDE.md`](CLAUDE.md). Build instructions follow once the CMake skeleton
lands (Phase 0).
